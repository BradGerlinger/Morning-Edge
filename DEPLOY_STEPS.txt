MORNING EDGE V1.3 — PAPER SCALPING UPGRADE

IMPORTANT: This is an automatic LOCAL PAPER simulator, not actual broker order placement.
It does NOT place live trades, and it does not send orders to Alpaca's paper broker.

STEP 1 — REPLACE CODE IN THE EXISTING REPO
1. Download Morning_Edge_V1_3_Paper_Scalper.zip.
2. Unzip it using Files on the iPhone or a computer.
3. Open the GitHub repository connected to your existing Morning Edge Render app.
4. Upload the unzipped files to the ROOT of the repository, replacing files of the same name.
   Make sure the NEW edge_engine.py file is uploaded too.
5. Do not upload the ZIP itself as the only repository file. Do not upload a .env or database.

STEP 2 — ADD ALPACA DATA KEYS
1. Obtain credentials from your Alpaca account (paper credentials recommended).
2. In Render, open the Morning Edge service > Environment.
3. Add ALPACA_KEY_ID and ALPACA_SECRET_KEY as separate SECRET environment variables.
4. Set ALPACA_DATA_FEED = iex (development feed; SIP needs an eligible plan).
5. Never paste credentials in ChatGPT, GitHub, or your browser source code.

STEP 3 — REDEPLOY
1. Render Settings: Python build command = pip install -r requirements.txt.
2. Start command = uvicorn server:app --host 0.0.0.0 --port $PORT --loop asyncio --http h11.
3. Use a single Render instance/worker. If using a persistent disk, mount /var/data.
4. Once deployed, visit the EXISTING app URL, not a second app.
5. Header must say MORNING EDGE V1.3 and PAPER SIMULATOR ONLY.
6. FEED STATUS should say RUNNING during market hours; market closed after hours.
7. If it says SETUP NEEDED, the data keys are absent. If it says DATA ERROR,
   open SERVER HEALTH and examine Render Logs (never reveal credentials).

WHAT IT WILL DO ON MARKET DAYS
- 8:30–8:45 Central: build the first-15-minute opening range from fresh stock bars.
- 9:00–10:30 Central: watch for confirmed one-minute breakouts or breakdowns.
- Record PENDING signals; simulate entry only on later bars, with automatic stop/target.
- Show P/L from paper entries and exits, not from imaginary fills on earlier candles.

CAUTIONS
- The FREE IEX market-data feed is not full-market data. This prototype has passed
  OFFLINE tests, not a live connection test. Do not assume returns are profitable.
- Database in /tmp WILL be lost on service replacement. Attach a persistent disk
  before depending on multi-day results. Changing paths does not copy the old DB.
- VIX/VXN is NOT integrated yet.
- Real money trading is HARD-DISABLED.
- No real broker bracket orders (paper or live) have been configured at this stage.
